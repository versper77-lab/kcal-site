KCAL 개인정보처리방침

시행일: 2026년 11월 16일

1. 수집하는 정보

KCAL 은 사용자가 Google 계정으로 로그인해 권한을 허용한 경우에만 그 계정의 Google 캘린더 목록과 일정(제목, 날짜·시각, 메모, 장소)을 읽습니다. 사용자가 KCAL 에서 일정을 추가·수정·삭제하면 그 내용을 사용자의 Google 캘린더에 반영합니다.

2. 정보의 보관

받은 일정과 로그인 토큰은 사용자 PC 의 KCAL 폴더(data\cache.json, data\settings.json)에만 저장됩니다. 로그인 토큰은 Windows 데이터 보호(DPAPI)로 암호화되어 같은 PC·같은 사용자만 풀 수 있습니다.

3. 제3자 제공

KCAL 은 어떤 정보도 개발자나 다른 서버로 보내지 않으며, 제3자에게 제공·판매하지 않습니다. 통신은 사용자 PC 와 Google 사이에서만 이루어집니다.

4. Google API 사용

KCAL 이 Google API 로부터 받은 정보의 사용 및 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 삭제 방법

KCAL 에서 「Google 연결 해제」를 누르면 PC 에 저장된 토큰과 일정이 지워집니다. Google 쪽 권한은 myaccount.google.com/permissions 에서 KCAL 을 삭제하면 해제됩니다.
